## ดูแบบ PDF
คลิกไฟล์ PDF บน GitHub ได้เลย GitHub แสดงในเบราว์เซอร์ หรือกด Download

## เปิดตัวนำเสนอ (deck.html)
GitHub แสดงไฟล์ .html เป็นโค้ด ไม่เปิดเป็นหน้าเว็บ ต้องโหลดลงเครื่องก่อน

1. โหลดโปรเจกต์: หน้า repo → ปุ่ม **Code → Download ZIP** แล้วแตกไฟล์ (หรือ `git pull`)
2. เข้าโฟลเดอร์ `06_Presentation/` แล้ว**ดับเบิลคลิก `deck.html`** — เปิดด้วย Chrome หรือ Edge
3. ต้องต่ออินเทอร์เน็ตตอนเปิด (ฟอนต์ IBM Plex โหลดจาก Google Fonts ถ้าไม่มีเน็ตฟอนต์จะเพี้ยน)

| ปุ่ม | ทำอะไร |
|---|---|
| คลิก / → / Space | จังหวะถัดไป (กดระหว่างอนิเมชันเล่นอยู่ = ข้ามไปจบจังหวะนั้น) |
| ← | ย้อน |
| F | เต็มจอ |
| M | เปิด/ปิดเสียง |
| ใส่ `#12` ท้าย URL แล้ว Enter | กระโดดไปสไลด์ 12 (ใช้ตอนตอบคำถาม เช่น `#26` = backup หน้าแรก) |

ตอนนำเสนอไม่มีเลขหน้าและคำบรรยายใต้ภาพ (ข้อมูลเต็มจอ) — ข้อความสรุปของแต่ละหน้าอยู่ใน PDF
